# CampusTwin 2.0 · 校园活动资源预演

一个使用虚构校园、虚构场景和示意插画的交互式演示项目。项目展示场地检索、活动申请、审核流程、确定性调度、前后变化对比、离线规则对话预演、可旋转三维校园和七幕答辩演示。

所有建筑、场地名称、人物、场景与资源参数均为演示数据，示意插画和三维模型不描绘任何真实校园。数据保存在当前浏览器本地；此项目不连接真实预约系统、登录服务或大模型。

## 启动

要求 Node.js 20 或更高。

```bash
npm ci
npm run dev
```

生产构建与检查：

```bash
npm run build
npm test
```

演示流程：进入「3D 演示空间」，拖动校园模型；在「变化前后」调整条件，或者使用「对话式预演」；点击「一键答辩演示」播放完整故事。

## 项目结构

- `src/engine/`：候选生成、约束和评分算法。
- `src/services/`、`src/types/`：业务编排、方案存取和类型契约。
- `src/demo/`：交互界面、三维场景与虚构演示数据。
- `src/components/`、`src/pages/`、`src/styles/`：原调度工作台和样式。
- `src/data/`：构造的样例数据。
- `public/images/`：原创示意 SVG，未包含真实照片。
- `scripts/`：本地预览服务与测试脚本。

对话功能使用确定性规则解析；容量、冲突和设备依据演示数据计算。该项目是原型，不构成真实的预约或调度服务。
